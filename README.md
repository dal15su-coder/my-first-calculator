# my-first-calculator
My first calculator project using ChatGPT Codex


## 휴대폰 앱으로 설치하기

이 계산기는 설치 가능한 웹 앱(PWA)입니다. Play 스토어 등록이나 APK 파일 없이
홈 화면에 설치할 수 있으며, 앱 아이콘으로 열면 주소창 없이 실행됩니다.
최초 접속과 오프라인 파일 준비에는 인터넷 연결이 필요합니다.

1. 안드로이드에서는 **Chrome**으로 아래 사이트를 여세요.
   네이버·카카오톡 안의 브라우저라면 메뉴에서 외부 브라우저로 열거나 주소를 Chrome에 붙여 넣으세요.
   https://dal15su-coder.github.io/my-first-calculator/
2. 페이지에 **휴대폰에 앱 설치** 버튼이 나타나면 누르세요.
   버튼이 없으면 Chrome의 **⋮ → 홈 화면에 추가 → 설치** 또는 **앱 설치**를 선택하세요.
   메뉴 이름은 Chrome 버전에 따라 다를 수 있습니다.
3. 설치 확인 창에서 **설치**를 누르고, 홈 화면의 **나의 계산기** 아이콘으로 실행하세요.
4. 페이지 아래 **앱으로 설치하는 방법**을 펼쳐 **오프라인 사용 준비가 됐습니다** 안내를 확인하세요.
   이후 비행기 모드에서도 계산할 수 있습니다. 브라우저의 사이트 데이터나 저장 공간을 지우면
   오프라인 파일을 다시 받아야 합니다.

아이폰은 Safari의 **공유 → 홈 화면에 추가**를 이용하세요.
실제 Android/iPhone 기기의 설치 동작은 기기에서 확인해야 합니다.
계산은 서버로 전송되지 않으며, 서비스 워커는 앱 파일만 브라우저에 저장합니다.

### 추가된 파일

- `manifest.webmanifest`: 앱 이름, 시작 주소, 독립 창 실행, 아이콘 설정
- `sw.js`: 앱 파일 캐시 및 오프라인 실행
- `icons/`: 설치용 아이콘과 SVG 원본
- `index.html`: 계산기와 설치 안내

업데이트할 때 오프라인 파일 구성이 바뀌면 `sw.js`의 캐시 버전도 올려 주세요.
로컬 개발은 저장소 폴더에서 `python3 -m http.server 8000`으로 서버를 시작해 확인할 수 있습니다.
설치와 서비스 워커는 HTTPS 또는 localhost에서 동작합니다.
